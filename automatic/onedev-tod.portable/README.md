# <img src="https://rawcdn.githack.com/strausmann/ChocolateyPackages/abb46e32c11403fd6d6e75e9fa113cbd8dedc07b/icons/onedev.png" width="48" height="48"/> [onedev-tod.portable](https://community.chocolatey.org/packages/onedev-tod.portable)

Chocolatey package for [tod](https://code.onedev.io/onedev/tod), the official command-line tool for [OneDev](https://onedev.io/).

Downloads the upstream `tod.exe` (64-bit) and puts a `tod` shim on the PATH. Automatically maintained (chocolatey-au) against the `Release` builds of `onedev/tod` on code.onedev.io, which publishes no GitHub release assets.

The meta package [onedev-tod](https://community.chocolatey.org/packages/onedev-tod) always pulls the matching portable version.
